  - `trackBoardFit`:
    - Once, on its first call, it mounts `<div class="board-housing" aria-hidden="true">` as `#app`'s previous sibling (or the body's first child if there is no `#app`), and calls `skin(housing, "frame")`. A second call never mounts a second housing.
    - On each `apply()`, it also writes `--desk-x` and `--desk-y` (`${x}px`) on the root from `deskOrigin(innerWidth, innerHeight)`. It writes them whether or not the window is a desk; CSS uses them only under `body.desk`.

- `board.css`, in the stage section after `#app`:

  ```css
  /* The PC desk (#376): the desk tile and its one dim pool of lamplight share an even-pixel
     origin from board-fit.ts, at exactly 2x, outside the board's zoom. */
  body.desk {
    background:
      url("./assets/board/desk-pool.png") var(--desk-x) var(--desk-y) /
        calc(var(--art) * 340) calc(var(--art) * 480) no-repeat,
      var(--board-desk) url("./assets/board/desk.png") var(--desk-x)
        var(--desk-y) / calc(var(--art) * 128) calc(var(--art) * 96) repeat;
    image-rendering: pixelated;
  }

  /* The steel housing: the frame skin, 8 board px round the board, scaled with it. Outside
     #app, so it takes no tap and no measure. */
  .board-housing,
  .board-housing.board-skinned {
    position: fixed;
    inset: 0;
    display: none;
    width: calc(var(--board-w) + var(--art) * 8);
    height: calc(var(--board-h) + var(--art) * 8);
    margin: auto;
    zoom: var(--board-scale, 1);
    pointer-events: none;
  }

  body.desk > .board-housing {
    display: block;
  }
  ```

  The doubled selector matters. `skin()` adds `.board-skinned`, and `.board-skinned:not(.board-note) { position: relative }` (0,2,0) would otherwise pull the housing back into the flex row beside `#app`. Prefer the doubled selector over widening that `:not()`. Prettier formats the block; the token check passes, since every length is `--art` or a token.

The desk row checks the canvas has width on every PC size. A rotate or resize test is in `board-fit.test.ts` only as the class toggle; the browser row proves the paint.
